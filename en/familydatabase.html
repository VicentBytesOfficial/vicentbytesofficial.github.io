What is it?

Features

  • LAN file transfer (compatible with Hamachi and other VPNs)
  • Available file listing directly from the interface
  • Multi-user support with username and password authentication
  • global/ folder shared between all users
  • Graphical interface built with CustomTkinter for the client
  • Administration console for managing users
  • Protection against path traversal attacks
  • Can be compiled as .exe (Windows) or .app (macOS), without requiring Python to be installed

Technical Info

Protocol: TCP (raw sockets)

Default port: 5000

Authentication: JSON (users.json)

GUI: CustomTkinter

Python: 3.10+

Structure: Client/ + Server/ (server.py, console.py, client.py, GUI.py)
