What is it?

Features

  • File transfer over LAN (works with Hamachi and other VPNs)
  • File listing available directly from the interface
  • Multi-user support with username and password authentication
  • Shared global/ folder accessible to all users
  • CustomTkinter GUI for the client
  • Admin console for managing users
  • Path traversal attack protection
  • Can be built as a standalone .exe (Windows) or .app (macOS), no Python required

Technical Info

Protocol: TCP (raw sockets)

Default port: 5000

Auth: JSON (users.json)

GUI: CustomTkinter

Python: 3.10+

Structure: Client/ + Server/ (server.py, console.py, client.py, GUI.py)
