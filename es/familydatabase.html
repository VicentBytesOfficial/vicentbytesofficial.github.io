¿Qué es?

Características

  • Transferencia de archivos por LAN (compatible con Hamachi y otras VPNs)
  • Listado de archivos disponibles directo desde la interfaz
  • Soporte multiusuario con autenticación por usuario y contraseña
  • Carpeta global/ compartida entre todos los usuarios
  • Interfaz gráfica con CustomTkinter para el cliente
  • Consola de administración para gestionar usuarios
  • Protección contra ataques de path traversal
  • Se puede compilar como .exe (Windows) o .app (macOS), sin necesitar Python instalado

Info Técnica

Protocolo: TCP (sockets crudos)

Puerto por defecto: 5000

Autenticación: JSON (users.json)

GUI: CustomTkinter

Python: 3.10+

Estructura: Client/ + Server/ (server.py, console.py, client.py, GUI.py)
